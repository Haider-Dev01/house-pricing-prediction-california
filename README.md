# California House Price Prediction 🏡

A simple yet effective machine learning model to predict median house prices across California using the popular housing dataset.

## 📊 Project Overview
- **Goal**: Predict `median_house_value` based on location, income, rooms, and other features.
- **Dataset**: [California Housing on Kaggle](https://www.kaggle.com/datasets/camnugent/california-housing-prices)
- **Type**: Regression (Supervised ML)
- **Models Used**: Linear Regression, Random Forest, XGBoost
- **Evaluation Metrics**: MAE, MSE, R² Score

## 🛠️ Tools & Libraries
- Python
- Pandas – Data processing
- Matplotlib/Seaborn – Visualization
- Scikit-learn – Machine Learning
- Jupyter Notebook
